# Extensiones de Odoo

Esta carpeta está vacía a propósito: el proyecto sigue la regla **configurar antes que programar** (sección 8.2 del documento).

Solo se agregará un módulo aquí si la prueba de concepto demuestra una brecha funcional documentada, por ejemplo un campo «estado operativo» en el pedido de venta (ver `docs/pipeline-estados.md`). Cada módulo debe tener su ADR en `docs/adr/`.
